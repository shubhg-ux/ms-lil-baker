# Ms. Lil Baker

Website for Ms. Lil Baker, Delhi home bakery.

## Project
Customer-facing bakery website with menu, cart, checkout/order request flow, custom-order form, and an admin dashboard prototype.

## Dynamic backend
The project includes `supabase-schema.sql` and `config.js` for connecting a Supabase database. See `README-DYNAMIC.md` for setup and security notes.
